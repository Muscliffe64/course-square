# 首页帖子展开与详情入口设计

## 目标

让首页的作品与分享帖子更易浏览：封面图不占据过多空间，读者可以不离开首页阅读完整正文，并能一眼找到进入详情页的入口。

## 范围

1. 首页卡片中的封面图使用统一的较小展示高度；图片按比例完整显示，不裁切。
2. 正文初始显示摘要。摘要未涵盖全部正文时，显示带向下箭头的“展开全文”按钮。
3. 点击展开按钮后，在当前首页卡片内显示完整正文；按钮变为“收起全文”并指向上方。再次点击恢复摘要。
4. 每张卡片增加清晰的“查看详情”链接；标题与封面图继续可点击进入详情页。

## 交互与边界

- 只展开文字正文。现有音频播放控件继续可在首页直接使用；视频继续引导至详情页播放。
- 正文未超过摘要长度时，不显示展开按钮。
- 展开/收起不请求服务器，也不改变点赞、评论、播放等现有操作。
- 不将整张卡片做成链接：卡片内部已有播放、点赞、评论和展开等独立控件，整卡可点击会造成误触与无障碍问题。

## 验收标准

- 首页封面图比当前展示明显更紧凑，同时能完整看见图片。
- 长正文可通过向下箭头在首页展开并收起，内容与详情页正文一致。
- 用户可通过标题、图片或“查看详情”进入帖子详情页。
- 手机和桌面布局均可正常使用，既有点赞、评论和媒体播放不受影响。
