## 改了什么

### 1. 讲次（Lecture）和「排进第 N 讲」

- 新模型「讲次」：第几讲、主题、上课日期。**在后台「讲次」里先把这学期的课排进去**，下面几项都依赖它。
- 帖子可以排进某一讲。教师有三个入口：帖子详情页右侧的「排进讲次」、首页投票里每行的「排进第 N 讲」、待回应页。
- 排进之后：帖子上显示「排进第 3 讲」，上课日期过了自动变成「✓ 第 3 讲讲过」；作者会收到站内通知「老师把你的帖子排进了第 3 讲」。同一讲重复排不会重复通知。
- 课程资料也可以挂到某一讲（后台编辑资料时选），列表上会显示「第 N 讲」。
- 原来的「状态」字段保留：排进讲次会同时把状态设成「已计划」，取消排课会退回「开放」。

### 2. 教师「待回应」页（`/pending/`，只有教师能进）

- **帖子**：学生发的、还开放、没排进讲次、你没在下面留过言的。
- **留言**：学生写的、之后同一帖子下你还没说过话的。
- 你在帖子下留言、把帖子排进某一讲、或者点「无需回复」，这一条就从列表里消失。
- 侧栏多了「待回应」入口和数字。学生看不到这个入口，直接访问返回 403。
- 最早的排在最前面。9 月 17 日那条留言如果当时有这个页面，就会一直顶在最上面。

### 3. 站外提醒（推送到手机）

- `manage.py notify_pending`，由 systemd timer 每 30 分钟跑一次。上次推送之后出现了新的待回应（帖子、留言、小票），才会发一条；没有新内容就不发。
- 推送内容：新增了几条、目前一共积压多少、前 5 条的标题或摘要，再加一个待回应页的链接。**不含学生姓名**，但帖子标题和留言摘要会经过第三方推送服务。
- 支持 Server 酱（推到个人微信，推荐）、企业微信、飞书、钉钉的群机器人。推送失败不会记为已发，下次会连同新内容一起重试。
- 可以设免打扰时段，例如 23-8，这段时间攒着，到点再发。

**启用方法**（在服务器上）：

```bash
# 1. 到 https://sct.ftqq.com 用微信扫码登录，拿到 SendKey
# 2. 写进环境文件：
sudo tee -a /etc/course-square.env >/dev/null <<'ENV'
TEACHER_NOTIFY_WEBHOOK=https://sctapi.ftqq.com/你的SendKey.send
COURSE_SITE_URL=https://123.57.56.38
TEACHER_NOTIFY_QUIET_HOURS=23-8
ENV
# 3. 先看看会发什么（只打印，不发送）：
sudo bash -c 'set -a; source /etc/course-square.env; cd /opt/course-square/current && .venv/bin/python manage.py notify_pending --dry-run'
# 4. 真发一次，看结果：
sudo systemctl start course-square-notify.service && journalctl -u course-square-notify -n 5 --no-pager
# 5. 看定时器：
systemctl list-timers course-square-notify.timer
```

### 4. 首页一行发帖 + 课后小票

- 首页（全部动态、下节课想听、作品与分享三个标签）顶部多了一个输入框：写一句话就能发，第一句自动当标题，可选栏目和匿名。
- 勾「只给老师看」就不会发到广场上，而是作为**课后小票**交给老师：实名、只有老师能看到，挂在最近一次已上过的那一讲下。界面上写明了「老师会在课上统一回应，不单独回复」。
- 要加图片、链接或写长文，旁边有「完整编辑器」入口，原来的发帖页不变。
- 出错时（空内容、超长）输入不会丢；双击或刷新重复提交，30 秒内同一内容只记一次。
- 后台「课后小票」可以按讲次筛选、看真名。导出：在「讲次」列表勾选某几讲，动作选「导出所选讲次的课后小票」。导出的 CSV 里姓名换成了代号（如 `S3F9A2C`），同一个学生在各讲里代号相同，可以直接交给平台外的摘要 skill。

### 5. 首页「下节课想听什么 · 投票」

- 放在全部动态和「下节课想听什么」两个标签的第一页顶部。筛本周或翻页时不显示。
- 候选：还开放、没排进讲次的提问，按赞同数排序，取前 5 条。**点 ♥ 就是投一票**，沿用原来的「我也感兴趣」，所以不存在两套计数。可以投多条，再点一次撤回。
- 文案写明：「截止到第 N 讲（日期）上课前，票数最高的一条，第 N 讲一定讲。」没有设置讲次时写「下节课一定讲」。
- **这个承诺要靠你兑现**：上课前把第一名排进那一讲，它就会从投票里移出，换下一批候选。第一名并列时，教师能看到提示。

### 6. CSS 收口

- 最小字号 12px（原来 8–11px 共 77 处）；正文类小字整体上调一档。
- 对比度不达标的文字色：灰色统一到 `--muted`（#687064，白底 5.1:1，页面米色底 4.7:1）；彩色标签按原色相加深到 4.6:1 以上。帖子正文和评论改用正文色。
- 字重 650/550 改为 600/500；删掉从未加载的 Inter 字体。
- 阴影改成看得见的两档，卡片悬停轻微抬起，按钮有按压反馈；通知跳到某条评论时会闪一圈高亮。系统设了「减少动态效果」时都会关掉。
- `base.html` 里的内联 `<style>` 搬进了 `app.css`。
- **修了一个手机端的老问题**：390px 宽时整页可以横向拖动（scrollWidth 469），原因是横向导航把页面撑宽了。

**没有做的**（学生方案里有，但这次没做）：间距统一到 4px 栅格、深色侧栏、深色模式、配色工作室、导航滑块动画、自定义类别、浏览量。

## 部署

跟以往一样用 `install.sh`，它会先备份、再迁移、收集静态文件、重启，这次还会装上提醒定时器：

```bash
bash deploy/install.sh 123.57.56.38
systemctl is-active course-square course-square-notify.timer
```

上线后请照着这张表点一遍：

| 操作 | 应该看到 |
|---|---|
| 后台「讲次」添加第 3、4 讲 | 首页投票写着「第 3 讲一定讲」 |
| 学生账号在首页输入框写一句，发布 | 回到原标签页，新帖在最上面，标题是第一句 |
| 刷新；换一个学生账号 | 帖子还在，别人也能看到 |
| 勾「只给老师看」再发 | 广场上没有；后台「课后小票」里有，带真名 |
| 在投票里点 ♥，刷新 | 票数 +1，按钮变实心；再点一次撤回 |
| 教师在投票里点「排进第 3 讲」 | 帖子显示「排进第 3 讲」，作者收到通知 |
| 学生账号访问 `/pending/` | 403 |
| 教师看侧栏「待回应」，去回复一条 | 回复后那条从列表里消失，数字减一 |
| 配好 Server 酱后，学生发一条 | 30 分钟内手机收到推送 |
| 手机打开首页 | 不能左右拖动 |

## 回退

迁移 0010 只新增表和可空列，两个新的布尔列带数据库默认值，旧代码照常读写（已验证：按旧代码的字段插入帖子成功）。所以切回上一个 release 不需要恢复数据库：

```bash
sudo systemctl disable --now course-square-notify.timer
PREV=$(cat /opt/course-square/previous-release.txt)
sudo ln -sfn "$PREV" /opt/course-square/current && sudo systemctl restart course-square
```

讲次、小票、排课记录会留在数据库里，重新上线后都还在。
